# GymBuddy.

A sleek, premium dark mode mobile onboarding screen for a fitness app. Background color is near-black charcoal gray (#121212). At the top, a clean white header reads "Select Your Equipment". Below it, a vertical list of three selectable cards: Card 1 says "Full Gym Machines", Card 2 says "Dumbbells Only", Card 3 says "Barbell Only". Cards change outline color to neon green when selected. At the bottom, a large full-width neon green button that reads "Generate My Routine". Heavy, generous padding and spacing throughout.
